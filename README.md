# RC排球 · ROBOCON 排球机器人资料

记录排球机器人的机械设计、结构参考和物料资料。仓库按 **2026、2027** 分年度存放，包含自建模型、收集的开源模型、BOM、比赛参考文件、照片及视频。

## 关于本次交接

本人接下来打算准备考研和大学英语六级考试，并进行电控相关知识的学习，因此将排球机器人相关的模型、图纸、BOM和参考资料整理到本仓库，作为工作交接，方便后续接手的同学查阅和继续完善。

仓库中的 **SolidWorks 原生文件请使用 SolidWorks 2025 或更高版本打开**。

本人能力有限，模型中可能存在不合理或尚未完善的地方。仓库资料仅供参考学习和工作交接使用。

## 2027 发球机器人

主装配体位于：

```text
2027/发球机器人/发球机器人/RC发球机器人.SLDASM
```

相关子装配包括底盘、发球架、顶球机构总成和顶球桩总装。建议先完整下载目录，再打开主装配体；保留原有文件名和相对目录，方便 SolidWorks 查找引用零件。

两份 Excel 物料表分别整理顶球部分和发球架物料。模型和表格作为设计过程资料保存，使用时应对照所需装配版本核对数量、尺寸和采购规格。

## 模型、工程图与参考资料

- **SolidWorks 原生文件**：`.SLDASM` 为装配体，`.SLDPRT` 为零件。完整下载引用文件后使用 SolidWorks 打开。
- **STEP / STP**：用于跨版本或跨软件查看和装配参考；通常不包含原生特征树及配合关系。
- **DXF / DWG**：分布在轮组及收集的模型目录中，使用时确认单位、比例和对应零件版本。
- **IM6014**：收集了电机模型以及快速安装、环抱安装、赛事推荐安装等结构参考。
- **GO-M8010-6**：补充了[官方3D模型、尺寸图、中英文手册、接口图和控制开发资料](2027/素材/宇树M8010/README.md)，包括官方SDK源码快照与STM32 HAL通讯例程；下载来源与校验信息随文件保留。
- **M3508 P19**：保留官方使用说明、安装尺寸图及[来源与尺寸说明](2027/素材/M3508官方工程图/官方来源与尺寸说明.md)。
- **RM论坛模型**：按原目录保留福州大学浮舟湿地战队、东北大学秦皇岛分校等队伍的排球机器人结构资料。
- **OpenTpuOmniWheel**：保留原项目的[README](2026/泡泡轮/OpenTpuOmniWheel-main/README.md)、[LICENSE](2026/泡泡轮/OpenTpuOmniWheel-main/LICENSE)、轮组模型及相关二维图纸。

`官方比赛文件` 中当前收录的是 **2026《沙排之王》比赛规则 V2**。目录归档位置不代表规则适用于2027；具体参赛要求应查阅对应届次正式规则。

## 下载模型与其他资料

大模型、开源演示视频及部分压缩包使用 **Git LFS** 保存；2026年现场视频请使用上面的夸克链接。建议安装 Git 和 Git LFS 后克隆：

```bash
git lfs install
git clone https://github.com/cairuijie-cai/RC-volleyball.git
cd RC-volleyball
git lfs pull
```

如果先前跳过了大文件下载，进入仓库目录执行 `git lfs pull` 即可补齐。若下载的文件只有几行文本、以 `version https://git-lfs.github.com/spec/v1` 开头，那是LFS指针，需要拉取实际文件后再打开。

GitHub 网页适合查阅目录和说明。获取需要外部零件引用的装配体时，推荐完整克隆，避免只下载一个 `.SLDASM` 文件。
