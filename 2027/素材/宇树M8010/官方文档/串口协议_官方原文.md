# GO-M8010-6 
## 串口配置
GO-M8010-6 电机采用串口通信，通信标准为 **RS-485**，波特率为 **4.0 Mbit/s**。串口的数据位为 **8 bit**，无奇偶校验位，停止位为 **1 bit**。需要注意的是为了提高电机的通信频率，我们使用了 **4.0 Mbit/s** 这一很高的波特率，用户需要检查自己的硬件是否支持这么高的波特率。
> 如果您的硬件无法支持该波特率，可选购 Unitree 设计制造的 USB 转 RS-485 模块。

## 电机运动控制协议

主机发送 **17 Byte 控制帧** 后，GO-M8010-6 电机返回 **16 Byte 反馈帧**。如果主机不发送控制帧，电机不会主动返回状态。

> **协议中的扭矩、速度、位置默认均为电机转子侧数据，而非输出端数据。**
>
> GO-M8010-6 电机转子到输出端的减速比为 `6.33`。

### 通信方向与包头

| 方向 | 帧长度 | 包头 | 说明 |
| --- | --- | --- | --- |
| 主机 -> GO-M8010-6 电机 | 17 Byte | `0xFE 0xEE` | 控制帧 |
| GO-M8010-6 电机 -> 主机 | 16 Byte | `0xFD 0xEE` | 反馈帧 |

### mode 字段说明

`mode` 字段占 **1 Byte**，由电机 ID、工作模式和超时标志组成，具体位域划分见下方控制帧格式表格。

> **切换到编码器校准模式后，需要等待 5s 再进行通信。**
>
> 等待期间不要向电机发送任何数据包，否则可能导致标定失败。

### 主机 -> GO-M8010-6 电机：控制帧格式

| 字节范围 | bit | 字段 | 类型 | 长度 | 说明 | 写入原始值 |
| --- | --- | --- | --- | --- | --- | --- |
| 0-1 | - | `head` | `uint8_t[2]` | 2 Byte | 控制帧包头 | 固定为 `0xFE 0xEE` |
| 2 | 0-3 | `mode.id` | bit field | 4 bit | 电机 ID | `0~14`；`15` 表示广播，无返回 |
| 2 | 4-6 | `mode.mode` | bit field | 3 bit | 工作模式 | `0` 锁定；`1` FOC 闭环；`2` 编码器校准；`3~7` 保留 |
| 2 | 7 | `mode.timeout` | bit field | 1 bit | 超时保护 | `0` 关闭；`1` 开启 |
| 3-4 | - | `cmd.torque` | `int16_t` | 2 Byte | 期望转子输出扭矩 | $\tau \times 256$ |
| 5-6 | - | `cmd.speed` | `int16_t` | 2 Byte | 期望转子输出速度 | $\frac{\omega}{2\pi} \times 256$ |
| 7-10 | - | `cmd.position` | `int32_t` | 4 Byte | 期望转子输出位置，多圈累加 | $\frac{\theta}{2\pi} \times 32768$ |
| 11-12 | - | `cmd.kp` | `int16_t` | 2 Byte | 期望转子刚度系数 | $\frac{k_p}{25.6} \times 32768$ |
| 13-14 | - | `cmd.kd` | `int16_t` | 2 Byte | 期望转子阻尼系数 | $\frac{k_d}{25.6} \times 32768$ |
| 15-16 | - | `crc16` | `uint16_t` | 2 Byte | CRC16_CCITT 校验值 | 覆盖前 15 Byte |

### GO-M8010-6 电机 -> 主机：反馈帧格式

| 字节范围 | bit | 字段 | 类型 | 长度 | 说明 | 物理量换算 |
| --- | --- | --- | --- | --- | --- | --- |
| 0-1 | - | `head` | `uint8_t[2]` | 2 Byte | 反馈帧包头 | 固定为 `0xFD 0xEE` |
| 2 | 0-3 | `mode.id` | bit field | 4 bit | 电机 ID | `0~14`；`15` 表示广播，无返回 |
| 2 | 4-6 | `mode.mode` | bit field | 3 bit | 工作模式 | `0` 锁定；`1` FOC 闭环；`2` 编码器校准；`3~7` 保留 |
| 2 | 7 | `mode.timeout` | bit field | 1 bit | 超时状态 | `0` 未触发；`1` 已触发 |
| 3-4 | - | `feedback.torque` | `int16_t` | 2 Byte | 实际转子输出扭矩原始值 | $\frac{raw}{256}$ |
| 5-6 | - | `feedback.speed` | `int16_t` | 2 Byte | 实际转子输出速度原始值 | $\frac{raw}{256} \times 2\pi$ |
| 7-10 | - | `feedback.position` | `int32_t` | 4 Byte | 实际转子输出位置原始值，多圈累加 | $\frac{raw}{32768} \times 2\pi$ |
| 11 | - | `feedback.temp` | `int8_t` | 1 Byte | 电机温度，单位 ℃ | `-128~127` |
| 12-13 | 0-2 | `feedback.error` | bit field | 3 bit | 电机错误标识 | `0` 正常；`1` 过热；`2` 过流；`3` 过压；`4` 编码器故障；`5` 母线欠压；`6` 绕组过热；`7` 未标定 |
| 12-13 | 3-14 | `feedback.force` | bit field | 12 bit | 足端力原始值 | `0~4095` |
| 12-13 | 15 | `reserved` | bit field | 1 bit | 保留位 | 保留 |
| 14-15 | - | `crc16` | `uint16_t` | 2 Byte | CRC16_CCITT 校验值 | 覆盖前 14 Byte |

### 原始值范围

| 物理量 | 原始值类型 | 建议物理量范围 |
| --- | --- | --- |
| 刚度系数 | `int16_t` | $0.0 \leq k_p \leq 25.599$ |
| 阻尼系数 | `int16_t` | $0.0 \leq k_d \leq 25.599$ |
| 转子输出扭矩 | `int16_t` | $-4 \leq \tau \leq 4 \text{ N} \cdot \text{m}$ |
| 转子输出速度 | `int16_t` | $-804.00 \leq \omega \leq 804.00 \text{ rad/s}$ |
| 转子输出位置 | `int32_t` | $-411774.0 \leq \theta \leq 411774.0 \text{ rad}$ |

### CRC 与字节序

* **CRC 范围**：控制帧 CRC 覆盖前 15 Byte，反馈帧 CRC 覆盖前 14 Byte。
* **CRC 算法**：使用 `CRC16_CCITT`，可参考 Linux 内核中的 `crc_ccitt` 实现。
* **字节序要求**：协议中的多字节整型使用小端模式，低位字节在前。

## 参考代码

以下示例将协议结构体和浮点 / 定点转换函数放在同一个头文件中，保留控制 GO-M8010-6 电机所需的核心内容。

```c
#ifndef __GO_M8010_6_PROTOCOL_H
#define __GO_M8010_6_PROTOCOL_H

#include <stdint.h>
#include <stddef.h>
#include <string.h>

#define GO_M8010_6_PI2 6.28318f

#define SATURATE(_IN, _MIN, _MAX) \
    {                             \
        if ((_IN) <= (_MIN))      \
            (_IN) = (_MIN);       \
        else if ((_IN) >= (_MAX)) \
            (_IN) = (_MAX);       \
    }

#pragma pack(1)

typedef struct
{
    uint8_t id      : 4;    // 电机 ID: 0~14；15 表示广播，无返回
    uint8_t mode    : 3;    // 0.锁定 1.FOC闭环 2.编码器校准 3.保留
    uint8_t timeout : 1;    // 超时保护标志
} MotorMode_t;             // 1 Byte

typedef struct
{
    int16_t torque;         // 期望转子输出扭矩，N·m，q8
    int16_t speed;          // 期望转子输出速度，rad/s，q8
    int32_t position;       // 期望转子输出位置，rad，q15
    int16_t kp;             // 期望转子刚度系数，q15
    int16_t kd;             // 期望转子阻尼系数，q15
} MotorRawCmd_t;           // 控制参数，12 Byte

typedef struct
{
    int16_t torque;         // 实际转子输出扭矩，N·m，q8
    int16_t speed;          // 实际转子输出速度，rad/s，q8
    int32_t position;       // 实际转子输出位置，rad，q15
    int8_t  temp;           // 电机温度，-128~127℃
    uint8_t error : 3;      // 0.正常 1.过热 2.过流 3.过压 4.编码器故障 5.母线欠压 6.绕组过热 7.未标定
    uint16_t force : 12;    // 足端气压传感器数据，0~4095
    uint8_t reserved : 1;   // 保留位
} MotorRawFbk_t;           // 反馈数据，11 Byte

typedef struct
{
    uint8_t head[2];        // 包头，2 Byte
    MotorMode_t mode;       // 电机控制模式，1 Byte
    MotorRawCmd_t cmd;      // 控制参数，12 Byte
    uint16_t crc16;         // CRC16_CCITT，2 Byte
} MotorControlPacket_t;     // 主机控制命令，17 Byte

typedef struct
{
    uint8_t head[2];        // 包头，2 Byte
    MotorMode_t mode;       // 电机控制模式，1 Byte
    MotorRawFbk_t feedback; // 反馈数据，11 Byte
    uint16_t crc16;         // CRC16_CCITT，2 Byte
} MotorFeedbackPacket_t;    // 电机返回数据，16 Byte

#pragma pack()

typedef struct
{
    uint8_t id;             // 电机 ID
    uint8_t mode;           // 工作模式
    float torque;           // 期望扭矩，N·m
    float speed;            // 期望速度，rad/s
    float position;         // 期望位置，rad
    float kp;               // 刚度系数
    float kd;               // 阻尼系数
    MotorControlPacket_t packet;
} MotorCmd_t;

typedef struct
{
    uint8_t id;             // 电机 ID
    uint8_t mode;           // 工作模式
    int8_t temp;            // 电机温度
    uint8_t error;          // 电机错误标识
    float torque;           // 实际扭矩，N·m
    float speed;            // 实际速度，rad/s
    float position;         // 实际位置，rad
    uint16_t force;         // 足端力原始值
    uint16_t calc_crc;
    uint32_t bad_msg;
    uint8_t valid;
    MotorFeedbackPacket_t packet;
} MotorData_t;

uint16_t crc_ccitt(uint16_t crc, const uint8_t *buffer, size_t len);

static inline void modify_data(MotorCmd_t *motor_s)
{
    motor_s->packet.head[0] = 0xFE;
    motor_s->packet.head[1] = 0xEE;

    SATURATE(motor_s->id, 0, 15);
    SATURATE(motor_s->mode, 0, 7);
    SATURATE(motor_s->kp, 0.0f, 25.599f);
    SATURATE(motor_s->kd, 0.0f, 25.599f);
    SATURATE(motor_s->torque, -127.99f, 127.99f);
    SATURATE(motor_s->speed, -804.00f, 804.00f);
    SATURATE(motor_s->position, -411774.0f, 411774.0f);

    motor_s->packet.mode.id = motor_s->id;
    motor_s->packet.mode.mode = motor_s->mode;
    motor_s->packet.cmd.kp = motor_s->kp / 25.6f * 32768.0f;
    motor_s->packet.cmd.kd = motor_s->kd / 25.6f * 32768.0f;
    motor_s->packet.cmd.position = motor_s->position / GO_M8010_6_PI2 * 32768.0f;
    motor_s->packet.cmd.speed = motor_s->speed / GO_M8010_6_PI2 * 256.0f;
    motor_s->packet.cmd.torque = motor_s->torque * 256.0f;
    motor_s->packet.crc16 = crc_ccitt(0, (uint8_t *)&motor_s->packet, sizeof(MotorControlPacket_t) - sizeof(motor_s->packet.crc16));
}

static inline void extract_data(MotorData_t *motor_r)
{
    if (motor_r->packet.head[0] != 0xFD || motor_r->packet.head[1] != 0xEE)
    {
        motor_r->valid = 0;
        return;
    }

    motor_r->calc_crc = crc_ccitt(0, (uint8_t *)&motor_r->packet, sizeof(MotorFeedbackPacket_t) - sizeof(motor_r->packet.crc16));
    if (motor_r->packet.crc16 != motor_r->calc_crc)
    {
        memset(&motor_r->packet, 0, sizeof(MotorFeedbackPacket_t));
        motor_r->valid = 0;
        motor_r->bad_msg++;
        return;
    }

    motor_r->id = motor_r->packet.mode.id;
    motor_r->mode = motor_r->packet.mode.mode;
    motor_r->temp = motor_r->packet.feedback.temp;
    motor_r->error = motor_r->packet.feedback.error;
    motor_r->speed = ((float)motor_r->packet.feedback.speed / 256.0f) * GO_M8010_6_PI2;
    motor_r->torque = ((float)motor_r->packet.feedback.torque) / 256.0f;
    motor_r->position = GO_M8010_6_PI2 * ((float)motor_r->packet.feedback.position) / 32768.0f;
    motor_r->force = motor_r->packet.feedback.force;
    motor_r->valid = 1;
}

#endif
```

uint16_t crc_ccitt_byte(uint16_t crc, const uint8_t c)
{
	return (crc >> 8) ^ crc_ccitt_table[(crc ^ c) & 0xff];
}

/**
 *	crc_ccitt - recompute the CRC (CRC-CCITT variant) for the data
 *	buffer
 *	@crc: previous CRC value
 *	@buffer: data pointer
 *	@len: number of bytes in the buffer
 */
uint16_t crc_ccitt(uint16_t crc, uint8_t const *buffer, size_t len)
{
	while (len--)
		crc = crc_ccitt_byte(crc, *buffer++);
	return crc;
}
