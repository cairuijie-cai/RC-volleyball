# 电机 SDK 介绍

当您购买了宇树科技的电机产品，可能会面临如何控制其转向角度、转速和扭矩的问题。为了解决这些问题，必须向电动机发送特定的控制指令。



# 为什么需要电机 SDK?
以`GO-M8010-6`电机为例：
现在，你希望让电机转动，需要向电机发送控制指令，来控制 **GO-M8010-6** 电机转动。
- 例如向 485 总线发送下述指令(16进制、波特率为 4000000、8n1模式)：
`FE EE 10 00 00 53 06 00 00 00 00 00 00 0C 00 4A 83` 
默认 ID 为 0 的 **GO-M8010-6** 电机输出端，将开始以大约每秒 1 圈的速度缓慢旋转。
- 并且电机会回复`16 Bytes`的反馈数据，例如：
`FD EE 10 00 00 FB FF 93 7A 00 00 22 A0 0E AE 17`

可以看到这样的数据是毫无可读性的，想了解这串数据所包含的信息，您需要参照 **GO-M8010-6** 电机的 [通讯协议](https://support.unitree.com/home/zh/Motor_SDK_Dev_Guide/communication_protocol) 结构。
但是，这需要掌握该电机的通讯协议的结构和转换方式，在日常的开发调试过程中，这是比较繁琐的工作，且比较容易出错。

为了协助您快速完成应用程序的开发，减少您使用电机协议的对接成本，宇树将相关通讯协议封装成 SDK，使您可以像调用程序函数、传参那样简单地控制电机。例如同样的控制指令，只需在代码里按如下设置：
```python
cmd.id = 0
cmd.mode = 1       # 0.刹车 1.FOC模式(解锁电机)
cmd.q = 0.0        # 转子期望位置 rad
cmd.dq = 6.28*6.33 # 转子期望转速 rad/s
cmd.kp = 0.0       # 位置误差比例系数
cmd.kd = 0.01      # 转速误差比例系数
cmd.tau = 0.0      # 转子期望前馈扭矩 N.m
serial.sendRecv(cmd, data) # 向RS485总线发送控制指令
```
将通信数据具象化、封装、调用，这就是电机 SDK 设计的初衷。

# 电机 SDK 支持情况
  当前支持的 Unitree 电机型号为：`GO-M8010-6` 、 `A1` 、`B1`
  支持的系统、平台：`Python`、 `C/C++` 、`STM32 HAL`

> 注意：
> 1. 电机的RS485的通讯波特率分别为: `GO-M8010-6 4Mbit/s`、 `A1 4.8Mbit/s` 、`B1 6Mbit/s`，我们建议购买电机时同时也购买附件包(内包含 USB 转 485 模块和线缆)，廉价的 USB 转 485 模块可能因为无法支持这么高的波特率导致无法正常使用！
> 2. 使用 STM32 开发的同学需要注意你的`单片机 (MCU)` 型号 `USART/UART` 外设是否支持到对应电机的波特率，以及 `485收发器芯片`是否也支持？

# 电机调试助手
Unitree 电机调试助手 是一个集成了电机通讯协议的调试工具，可方便用户进行电机控制、查看通讯数据等功能。
通过调试助手，您可以体验全部数据交互流程，熟悉电机的工作模式和特性，提高开发效率。开发调试电机过程遇到问题，也可通过此工具对比验证，确定问题归属。
建议第一次开发电机的客户，先使用该调试助手学习了解电机后，再着手编写应用程序代码。

[电机调试助手下载地址](https://support.unitree.com/home/zh/Motor_SDK_Dev_Guide/Motor_debugging_assistant)
